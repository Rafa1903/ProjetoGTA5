# ProjetoGTA5

O projeto acadêmico cujo objetivo é testar os conhecimentos de HTML.

O site consiste apresentar o jogo Grand Theft Auto V(GTA V) e mostrar diversas informações sobre:

1. História.
2. Personagens.
3. Músicas.
4. Mistérios do modo história.
5. Golpes do modo história.
6. GTA Online.
7. Mistérios do GTA Online
8. Gameplay.
9. Golpes do GTA Online

A principal e a única tecnologia usada foi a da html.
